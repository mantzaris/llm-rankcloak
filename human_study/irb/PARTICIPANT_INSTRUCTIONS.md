# DRAFT participant instructions — NOT IRB APPROVED

You will read short English messages from several writing and generation processes.
The source of each message is intentionally not shown. Please do not try to identify
the source; rate only what you see.

For every message:

1. Read the topic label and message once at a natural pace.
2. Answer all seven questions using an integer from 1 to 7.
3. Use the endpoint and midpoint descriptions as guides; intermediate values are
   allowed.
4. Treat informal language as potentially appropriate. Do not lower grammaticality
   only because a message is conversational.
5. Judge topic adherence against the displayed topic, not whether you personally like
   or agree with the message.
6. Judge suspiciousness from unexplained wording, formatting, repetition, or
   abruptness—not merely from an unfamiliar topic.

There are no correct quality ratings. Two separate items will explicitly ask for a
particular response to check that instructions are visible. You may stop by closing
the survey. Backtracking is unavailable after you submit a message page.
