# UCF IRB draft-material checklist — NOT SUBMITTED

This is a preparation checklist, not UCF guidance or approval. Confirm every item
against the current UCF submission system and templates.

Current institutional sources checked on 2026-08-09 are UCF IRB Guidance 07
(version 11/19/2025), the Huron IRB Library templates page, and the UCF IRB FAQ.
UCF, not the investigators, makes the final review-category determination.

## Author/institution fields

- [ ] PI eligibility, `{{PI_NAME}}`, `{{PI_EMAIL}}`, and `{{UCF_DEPARTMENT}}` verified.
- [ ] `{{FACULTY_ADVISOR_IF_APPLICABLE}}` resolved.
- [ ] Study-team roles/training and `{{AUTHORIZED_STUDY_TEAM}}` documented.
- [ ] `{{UCF_IRB_PROTOCOL_NUMBER}}` assigned by the institution, not invented.
- [ ] `{{FUNDING_SOURCE}}` and conflicts disclosed.

## Protocol attachments

- [ ] Current Huron IRB study application and Guidance 07 reviewed.
- [ ] Appropriate current protocol form selected with UCF: HRP-255 for a requested
      exempt determination or HRP-503 if UCF requires expedited review.
- [ ] If an exempt consent process is requested, current HRP-254 language used.
- [ ] Protocol reconciled with current UCF fields.
- [ ] Information sheet/consent language approved.
- [ ] Participant instructions and debrief approved.
- [ ] Seven-scale instrument and two attention checks attached.
- [ ] Recruitment/platform posting attached only after its text exists.
- [ ] Compensation and partial-completion policy consistent across documents.
- [ ] Power analysis and requested sample with attrition attached.
- [ ] Human-control licensing/provenance documented.
- [ ] Stimulus safety-screening criteria attached.
- [ ] Exclusion and missing-data plan attached.

## Privacy and data management

- [ ] Survey platform and `{{SURVEY_PLATFORM_PRIVACY_SETTINGS}}` documented.
- [ ] Platform agreement/institutional approval confirmed if required.
- [ ] Direct identifier, IP, cookie, and location collection disabled where possible.
- [ ] Payment/contact file separated from responses.
- [ ] Blind key restricted and excluded from cleaning exports.
- [ ] UCF-approved storage, access list, encryption, backup, and deletion described.
- [ ] `{{DATA_RETENTION_YEARS}}` reconciled with UCF and publisher requirements.
- [ ] Public data-sharing scope and DOI materials described.

## Determinations required from UCF

- [ ] Review category/risk determination.
- [ ] Whether withholding source-condition details is incomplete disclosure/deception.
- [ ] Adequacy and timing of debriefing.
- [ ] Waiver/alteration of signed consent, if requested.
- [ ] Handling of anonymous withdrawal after submission.
- [ ] Recruitment jurisdiction/platform restrictions.

## Launch gate

- [ ] Required UCF Social/Behavioral CITI training completed before submission.
- [ ] Formal UCF determination received and recorded.
- [ ] Approved documents versioned and checksummed.
- [ ] All placeholders resolved.
- [ ] Final sample/power decision recorded.
- [ ] Synthetic fixture/test accounts removed.
- [ ] Separate written authorization to recruit recorded.

If any launch item is unchecked, recruitment and data collection remain prohibited.
