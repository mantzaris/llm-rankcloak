# Project Context

## Research Goal

RankCloak studies LLM rank-transcoding steganography for high-entropy cryptographic-artifact-like strings. The key question is whether fake hashes, random hex values, UUID-like strings, invalid token-like strings, HMAC-like tags, and ciphertext-like blocks can be carried through plausible generated cover text.

The main comparison is between:

- Direct raw subword-token encoding, where the artifact text is tokenized by the model tokenizer and each payload token is represented by its next-token rank.
- Bounded-rank encodings, where payload bytes or hex nibbles are mapped into small rank alphabets such as B=8 or B=16.
- Prompt families and cover genres that may absorb forced-rank damage better or worse.

## Source Context

The project is based on the Calgacus-style idea described in `references/2510.20075.pdf`:

1. Tokenize a secret or payload text.
2. Compute the rank of each payload token under an LLM.
3. From a key prompt, generate cover text by selecting the token at each corresponding rank.
4. Recover by recomputing the rank of each generated cover token under the same prompt and previous generated tokens.

The previous repository reference is represented under `external_sources/LlmStenoExplore/` when available. RankCloak uses the idea pattern but implements a cleaner local package focused on synthetic cryptographic-artifact-like payloads and reproducible result tables.

## Safety And Scope

RankCloak intentionally avoids real secrets and operational examples. The payloads are deterministic synthetic strings generated by `rankcloak/synthetic_payloads.py`.

The project does not claim:

- Encryption.
- Key exchange.
- Authentication.
- Credential protection.
- Cryptographic security.
- Robustness against editing, paraphrase, platform normalization, or active detection.

The current study is limited to exact-copy recovery with the same model, tokenizer, quantization, rank ordering, prompt, and generated text.

## Terminology

- Payload: the deterministic synthetic artifact-like string being carried.
- Cover prompt: the key prompt used to define the cover-side distribution.
- Rank: the 1-indexed position of a token in descending next-token logit order, tie-broken by token id ascending.
- Bounded-rank encoding: a payload-side transform that maps bits or hex characters into ranks constrained to 1..B.
- Direct subword encoding: tokenizing the artifact text directly with the LLM tokenizer and measuring the token ranks.
- Stegotext recovery: full generate-then-recover through cover tokens under the same model and prompt.
- Codec roundtrip: payload bytes to ranks and back without model generation.
