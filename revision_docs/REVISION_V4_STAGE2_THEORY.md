# Stage 2 theory and source audit

These arguments describe mechanisms and conditional bounds. They do not establish a new robust communication protocol or a causal attribution of detector performance. Historical code and configurations remain unchanged.

## Configuration sensitivity and a compatibility check

A decoder configuration includes the exact model and embedded tokenizer identities, quantization, backend and numerical policy, prompt rendering, BOS/EOS handling, deterministic ordering and mask, codec and framing, gate, and boundary/reset schedule. The new canonical fingerprint in `rankcloak/revision_v4_compatibility.py` hashes all eleven named components using the existing canonical JSON utility. A receiver rejects a missing component, inconsistent header, or configuration mismatch before attempting replay. The demonstration header and acceptance/mismatch evidence are in `results/revision_v4/stage2/compatibility`.

The check is not authentication. An attacker can replace an unauthenticated header, and equal declared configurations do not guarantee unchanged transport bytes or numerical determinism on an unrecorded environment. The fingerprint is not retroactively inserted into historical messages.

A tokenizer update can leave a particular string unchanged or split/merge its tokens. Thus a version number alone implies no recovery probability. Changed token IDs affect saved offsets and subsequent conditioning. Different model weights can alter ranks even with identical received tokens. Gate disagreements change which observed positions consume payload digits. Resets contain propagation only when their locations and initial contexts remain shared.

Let p_t denote the conditional chance of a rank disagreement at step t given agreement through t−1 under a specified message ensemble and mismatch. The probability of complete rank agreement is the product of (1−p_t), with no independent-error assumption needed under that definition. A union bound gives a lower bound of one minus the sum of unconditional disagreement probabilities. These are accounting identities, not measured failure forecasts. Byte recovery further depends on the codec, padding, framing and length checks. No per-token error rate is inferred from the observed zero cross-model endpoint.

## A proposed fallback

Identify and verify a supported configuration before decoding. A possible future transport can frame independently decodable blocks with sequence/length metadata and explicit context resets, reject failed integrity checks, use bounded outer error/erasure correction, and request retransmission when repair is outside the code's capability. For a block code of minimum distance d, unique correction requires 2e+s<d for e erroneous symbols and s located erasures under its declared channel assumptions. A checksum identifies accidental corruption only probabilistically. Authenticity requires a separately keyed mechanism.

This proposal requires reliable frame boundaries and correct identification of unavailable blocks. ECC cannot reconstruct an arbitrary wrong model codebook or correct persistent synchronization loss. Rejecting the incompatible configuration and negotiating a supported one is prior to payload repair. Retransmission over the same unresolved mismatch is ineffective. Metadata, redundancy, independent prefills and retries add length, compute and potential detection cues. No new recovery rate is claimed for this unimplemented fallback.

## The evaluated attacker and statistical detectability

The model-aware classifier consumes summary statistics of retained token log probabilities, not an independently retokenized public string. Reproduction requires the exact model, backend, original token IDs, prompts, segment resets and scoring convention. A visible-text scorer would be a separate experiment because retokenization can change that path. The full receiver configuration may also enable payload decoding. Detection does not itself demonstrate recovery, and surface syntax concealment does not establish confidentiality.

For a message ensemble, payload digits induce a distribution over contextual ranks. Bounding that rank is different from matching the ordinary sampler's probabilities. Structured serializations and forced/tail/skip schedules can also introduce statistical regularities. These observations explain a plausible source of the measured discrimination without identifying a unique cause or proving an impossibility theorem.

The ordinary reference samples at temperature 0.8 with top-p 0.95. The saved likelihood features use untempered full-vocabulary probabilities. Write Q for the cover-message ensemble and P for a specified reference. Under support and integrability assumptions, sequence KL is the expected sum of conditional KL terms. A top-p P can assign zero probability to a forced token with positive Q mass, making that KL infinite. This does not turn a finite observed AUC into a KL estimate. The evaluated adverse result therefore bounds the paper's claims without claiming all linguistic steganography must be detectable.

## Rank margins and quantization

For a fixed received history, suppose every allowed-token logit changes by at most epsilon in absolute value and the allowed set and tie rule remain identical. A pairwise logit gap greater than 2 epsilon retains its sign. Preserving the selected token's rank requires this protection against every relevant crossing, including its immediate upper and lower neighbors in a strictly ordered list. Exact ties and gaps at or below the bound have no such guarantee. This is a sufficient condition, not an empirical estimate of epsilon or the number of near ties.

After independent generators choose different tokens, later comparisons combine logit perturbations and different histories. By contrast, observed-token replay feeds received cover tokens into the model, not recovered payload symbols. An incorrect recovered rank alone does not feed a new cover history back into that replay. Retokenization, changing boundary offsets, regenerated lead-ins and disagreement about gate eligibility are additional mechanisms.

The 1,920 common-history pairs and 244,440 positions already support this distinction. Of 69,528 changed ranks, 56,321 occur at 122,220 encoded positions and 13,207 at 122,220 ordinary positions. The separate offline endpoint reconstructs original bytes from Q8 ranks on 960 fixed Q4 encoded token paths. Zero recover exactly, 766 have invalid bounded ranks, and 194 decode to different valid bytes. The endpoint does not use the independently generated Q8 path and supports no reverse-direction claim. No quantitative margin-distribution claim is needed, so the optional GPU margin replays were not run.

## Complexity against inspected algorithms

Let V be vocabulary size, A the allowed set, P_j the prompt length of segment j, T the emitted positions including lead-ins, skips and tails, and C the configured context limit. Let F(P_j) denote prompt prefill work and D(h_t) one incremental model evaluation at history length h_t. Define M as their sum over the actual sequence of calls. Transformer work and KV memory vary with those lengths and architecture. This notation avoids treating model evaluation as a hardware-independent constant.

RankCloak selection converts/enumerates arrays in O(V) and sorts all A candidates in O(A log A). Known-token recovery counts higher scores and lower-ID ties in O(A), still with O(V) conversion/mask work. Computing full-vocabulary log probability costs O(V), while entropy costs a vocabulary pass over admissible finite values. Rank-one selection for lead-ins and tails also calls the full sort. In the instrumented entropy loop, the selected-rank sort, diagnostic greedy sort and optional rank-B quality sort can coexist at a position. Ordinary top-p skips also sort and consume an LM step. The overhead is therefore M plus the sum of invoked sorts and probability passes, not a single sort multiplied by payload length.

The bounded byte codecs require ceil(8m/3) positions for B8 and 2m for B16 for m serialized bytes. Hex-nibble uses one position per displayed hex character. Direct-subword measurement adds a payload-context LM pass and rank counting, and its inverse adds a payload-context generation pass with rank selection. Segmentation repeats prompt prefills. Tails and rejected gate opportunities add work without consuming payload digits. Resetting prevents reuse of an earlier segment's KV state under the retained protocol.

The inspected Ziegler implementation sorts the full vocabulary before truncation, computes probabilities and cumulative finite-precision intervals, and scans the retained candidates to choose an interval. For fixed precision b and K retained candidates, this is O(V log V+V+K+b) non-model work per step. Decoding repeats these operations and includes optional tokenization repair, which adds data-dependent work. This is an implementation cost derived from the pinned primary source, not an assertion about every arithmetic coder. [Paper](https://aclanthology.org/D19-1115/) and [inspected source](https://github.com/harvardnlp/NeuralSteganography/blob/14e982564aeaf9a33f7b4de440deda2184d17f12/arithmetic.py).

The inspected SAAC code sorts full logits, uses a cumulative mass threshold to choose K, then rounds and updates arithmetic intervals. Its vocabulary sort remains O(V log V), with O(V+K+b) probability, scan and precision work. Adaptive truncation changes K and constants rather than removing the initial sort. The comparison retains the model call and optional sentence completion overhead. [Paper](https://aclanthology.org/2020.emnlp-main.22/) and [inspected source](https://github.com/mickeystroller/StegaText/blob/125f1b23b2ff0316320ad5aa3a7db1f029129a1d/saac.py).

ADG Algorithm 1 sorts probabilities, repeatedly finds a nearest-probability candidate by binary search, removes it, updates group mass and recurses only into the selected group. For group sizes n_l along that recursion, efficient ordered-set search/removal and maintained sums permit O(sum n_l log n_l) grouping work in addition to probabilities. Literal array/list deletion or repeated mass summation can add O(sum n_l squared) work. The paper does not specify a universal constant-time deletion structure. Decoding must reconstruct the same groups. A blanket linear grouping cost would therefore be unjustified. [Primary algorithm, Sections 4.1–4.3](https://aclanthology.org/2021.findings-acl.268/).

Peak memory includes model weights, architecture-dependent KV storage growing with context length, O(V) temporary arrays, and O(CV) score storage requested by `logits_all=True`. Saved scalar diagnostics cost O(T) and are distinct from score buffers. Segments are processed sequentially, so their peak buffers do not all coexist. GPU kernels, host transfers, serial scheduling and precision determine constants. Neither these bounds nor historical inclusive wrapper timings establish superiority across backends.

Primary source revision hashes are retained in `results/revision_v4/stage2/provenance/primary_sources/manifest.json`. No comparator implementation was executed or installed.
