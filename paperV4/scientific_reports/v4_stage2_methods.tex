\subsection*{Boundary instrumentation and prospective control validation}\label{sec:v4-boundary-method}
We audited 8,280 forced-span to tail boundaries in 1,440 segmented trials from 240 payloads in four hexadecimal artifact classes. Every structural boundary remains in the inventory. We froze byte alignment, control assignment and exclusions before scoring. Actual transitions were paired with ordinary pseudo-boundaries at the same generator-token offset and with shuffled tails from a different payload under the exact same prompt. Ordinary matching retains the generator, exact prompt context, forced-stop offset and available right-window length. Shuffled tails additionally match schedule and forced length. Shuffled donor tails identical to their recipient tail were skipped under a declared rule even if their identities differed. No cross-topic donors were substituted. The retained RankCloak tails are greedy continuations, whereas ordinary controls use temperature 0.8 and top-\(p\) 0.95 sampling. This protocol comparison does not isolate the forced boundary from continuation policy.

The left window contains up to 32 generator tokens before the boundary. The initial right cap was 32, reduced to 16 in the sole predeclared pilot amendment. The selected corpus supplies eight left tokens and eight to sixteen right tokens. Short tails retain their available length, matched across arms. Each side needs three words. Full-prefix decoding locates exact UTF-8 byte boundaries. Each language-model evaluator tokenizes the joint visible window independently. A token that straddles the boundary makes that unit unavailable. A recorded single leading-space rendering prefix in the Mistral tokenizer is accounted for explicitly. The generator's token IDs are never interpreted using another tokenizer.

Semantic relatedness uses the purpose-trained \code{sentence-transformers/all-MiniLM-L6-v2} encoder and its official attention-mask mean pooling, L2 normalization and 256-token truncation\cite{Reimers2019SentenceBERT}. The pinned local revision, all required file hashes, Apache 2.0 license and float32 runtime are archived. No fitted RankCloak detector supplies embeddings. The complementary metric uses the existing evaluator map, Llama text scored by Qwen, Qwen by Mistral and Mistral by Llama. For the same evaluator tail-token path \(y_{1:n}\), it measures
\begin{equation}
G=\frac{1}{n}\sum_{i=1}^{n}\left[\log p_E(y_i\mid P,L,y_{<i})-\log p_E(y_i\mid P,y_{<i})\right],
\label{eq:v4-context-gain}
\end{equation}
where \(P\) is the evaluator-tokenized rendered prompt, including its declared BOS policy, and \(L\) is the evaluator-token prefix of the joint visible left/right window. The sequence \(y_{1:n}\) is the remaining suffix of that joint tokenization. Both contexts append these exact target IDs and share denominator \(n\). The prompt-only pass reuses these tail IDs even if standalone tail tokenization differs. Raw mean conditional tail log likelihood is retained as a secondary measure. This is a fixed-token-path contrast, not the difference between independently tokenized string likelihoods. Whole-message likelihood is not substituted for a boundary measure.

Each control-only pilot selected 36 identities by a frozen SHA256 rule across generator, schedule and prompt category. The validation requirement was a positive lower 95\% payload-cluster interval for ordinary minus shuffled ordinary transitions on both primary metrics. The amendment used fresh recipient and donor payloads. RankCloak metric outcomes were unavailable during those decisions. Following the failed semantic validation, the subsequent study is explicitly exploratory and uses the context-gain measure that passed the specified control-separation check. A conservative measured-cost forecast selected 23 payloads per artifact class by identity hash before RankCloak scoring. All three models, both schedules and eligible boundaries of each selected trial were retained. Segments are averaged within trial and trials within payload. The 2,000 bootstrap draws resample payloads within artifact class and are identical across arms and models. These unadjusted exploratory intervals condition on the fixed control corpus. Donor reuse and leave-one-donor-payload-out influence are reported separately. Neither proxy establishes reader judgments or coherence between messages whose prompts deliberately rotate.

\subsection*{Decoder compatibility and bounded transport diagnostics}\label{sec:v4-compatibility}
The canonical configuration fingerprint includes model and tokenizer identities, quantization and backend, prompt rendering, BOS/EOS policy, ordering, filter, codec/framing, gate, and boundary/reset contract. The new compatibility API accepts a matching canonical header and rejects incomplete, corrupted or mismatched configurations. Tests change each component independently. This is a compatibility check, not authentication, error correction or proof of confidentiality. It was not retroactively added to the historical covers.

The transport diagnostic selects at most one original visible-text success and failure per source model by identity hash. An audit found that the historical raw ``unmodified'' reference points to saved-token recovery. Visible baseline labels therefore come from executed historical text-transform replays only when every observed byte equals the source text. The historical references and composite Markdown outcomes remain unchanged. Missing strata are unavailable. Five selected covers support at most 25 decomposed arms. We add only missing model-input replays for per-line prefix insertion, outer trimming, trailing trimming, line-ending normalization and removal of the declared blockquote wrapper. Wrapper removal strips exactly the declared prefix and cannot inspect payloads or search for a successful offset. Source bytes, retokenized IDs, saved-offset spans, recovered ranks and bytes are retained in Supplementary Note S18.
